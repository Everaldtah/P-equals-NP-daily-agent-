# L-pcx-412 (run 6, 2026-11-27 20:04Z)

Unit: "Sharp coordinate budget for simultaneously falsifying one used extension clause per advice word
on pigeonhole graphs". solid prove, 44 points. Lease eeb04108-c326-4a88-bc7f-9a5abd5fb841.
File lean/PEqualNP/Outside/L_pcx_412.lean (statement: exists C n0, 2<=C, for n>=n0 a bipartite graph
G : BipGraph (n+1) n with left/right degree <= C, nonempty pigeons, and for all t d w:
(A) if C*B < n (B = sum d_j w_j) every resolution refutation of lift(funGraphPHP G) ∪ extra with
advice polynomials P (deg <= d_j) and menu bits, narrow (<= w_j) or menu-guarded clauses, has one
extra clause per word cl j in pi and, for every invertible linear L and shift z, a set U of <= B
coordinates with an odd number of common falsifying points in every U-subcube;
(B) an explicit such proof of size <= C(q+t+1), q = min n B, whose extra is falsified by every word
exactly when the q pigeons of a set J are all placed.)

## Analysis
- Part A reduces (the cube is invariant under invertible affine maps, and a nonzero function of
  degree <= B has an inclusion-maximal monomial U, |U| <= B, with derivative 1 on U) to: some choice
  of one extra clause per word in pi, with no true menu literal, is falsified by ONE common x.
  Width/degree of each falsification indicator <= d_j w_j, so their product has degree <= B.
- Proof of that: by contradiction, translate each word's refutation into a PC derivation of 1
  (falsifying polynomials, each resolution step in degree 3 d_j w_j), multiply the t derivations;
  the all-extra term vanishes by assumption, so funGraphPHP G is PC refutable in degree ~3B, against
  library L049 (no PC refutation of degree D when d*D <= s, G an (s,2) boundary expander) with
  G from L043 (bounded degree (n/s0, 2)-expanders, n+1 pigeons). Choose C >= 3*b*s0 + b.
  Nonempty pigeons follow from expansion of singletons.
- A trivial G does not work: with a pigeon of degree 1 sharing its hole, extra = ∅ has a width-2
  refutation and (A) fails. So (A) really needs the expander lower bound.
- Part B construction (checked on paper): split J (|J| = q <= B) into bins of <= d_j w_j pigeons,
  bin j into <= w_j batches of <= d_j. Menu: h = t, menu j k = (j = k) (guard g_j). Extension vars:
  v_i = prod_e (1 + x_e) (pigeon i empty, degree <= b) for every word; prefix ORs s_{j,k,m} of the
  v's in batch k of bin j (degree <= b*d_j), polynomial 0 under other words. Extra: ¬v_i ∨ ¬x_e;
  ¬s_{m} ∨ s_{m-1} ∨ v_{i_m}; D_j = ¬g_j ∨ (last s of each batch of bin j); G = {g_1..g_t}.
  Refutation: pigeon clause + ¬v_i∨¬x_e gives ¬v_i; walk down each chain to ¬s_last; D_j gives ¬g_j;
  G gives ∅. All clauses width <= max(b,3) or w_j+1 with the guard, length O(b(q+t+1)).
  Under word j only D_j can be falsified, and exactly when bin j is full.

## Outcome
Both halves need long formalizations (a resolution-with-advice to PC simulation and product of
derivations for A; a concrete list-built refutation with a length bound and the iff for B). Not
doable in one 60-minute run. Released as missing_lemma at about 20:24Z.
