# L-pcx-416 (run 6, 2026-11-27 20:08Z, taken with --another while holding L-pcx-412)

Unit: "Exact rational feature dimension across a synchronized cut for all zero-pin queries on three
matchings". solid prove, 43 points. Lease 81fcaa8f-3d4b-4db6-a569-1aa4c5b32cb0.
Statement: for permutations sigma, tau of Fin n, a set A, rational z > 0, z != 1, the matrix
Z(P,Q) = sum over y in {0,1}^(2n) of z^energy(y), restricted to y zero on the pins (P pins the vertices
(either side) whose index is in A; Q pins those whose index is not in A), has a rank-d factorisation
over Q iff prod over components D of the "arc" graph of factor(D) <= d, where
factor(D) = 3*2^(|D|/2-2) if every vertex of D has degree 2 (a cycle) else 2^(|D|/2).
So: rank Z = prod factor(D).

## Work
- tools/pcx416_rank.py: computes the rank mod a large prime (the matrix only depends on which pins
  lie in P and Q) and compares it with the product. Pitfall: P may pin vertices on BOTH sides (my
  first version pinned only the false side and gave false "mismatches" at n = 2).
- All sigma, tau, A for n <= 3 with 132 rationals z = p/q (p, q <= 12), at two primes: 54720
  tests, 0 mismatches. n = 4, all 9216 (sigma, tau, A), one z each: 0 mismatches. The statement
  looks true. No special z where the rank drops was found.
- A Lean proof needs the whole rank calculation (tensor factorisation over components, the
  path and cycle 2-spin matrices, rank of a Kronecker product, the rank <-> factorisation
  equivalence) for all n: far beyond one run.
