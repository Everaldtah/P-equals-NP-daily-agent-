solid prove, 36 points, size large, no reductions. Over F_2: if rank-<=2 matrices R_1..R_t span all
X(A,K) = [[A,K],[K^T,0]] (A in S, K in B ⊔ P, B and P disjoint), then q = dim S + dim B <= t and,
after removing q coordinates, an injective linear code c on P with X(aK, K+bK) = sum c_j R_(e j) and
rank(K+bK) <= wt(cK).
Quick reading: q <= t holds because X is linear and injective; the rank bound follows from
rank X(A,K) >= 2 rank K and the subadditivity of rank (each R has rank <= 2). The hard part is choosing
the q coordinates (a section of the coefficient map, as in the sketch) and building e, a, b, c as
Lean linear maps. That is hours of Mathlib linear algebra.
