## The statement

```lean
def H1 : Prop := ∀ c : ℕ, Odd c → (∀ p ∈ c.primeFactors, 2 ≤ c.factorization p) →
    ∃ K : ℕ, ∀ a : ℕ, ∀ S : Finset ℕ,
      let b := 2 ^ a * c
      let u := ∏ p ∈ b.primeFactors, (1 + p ^ b.factorization p)
      5 ≤ a → 4 ≤ S.card → S ⊆ Finset.Icc 3 u →
      (∀ p ∈ S, p.Prime ∧ ¬ p ∣ b) →
      u * (∏ p ∈ S, (1 + p)) = (2 * b) * (∏ p ∈ S, p) →
      (S.filter (fun p => p ∣ 2 ^ a + 1)).card ≤ K
```

In words: u is the unitary divisor sum σ*(b), and the balance says N = b·∏S is a unitary perfect number
(σ*(N) = 2N) whose primes outside b appear once. H1 asks that, for each fixed squarefull odd c, the number
of those simple primes that divide 2^a+1 is bounded independently of a.

## What I did

1. **Checked the known examples.** Of the five known unitary perfect numbers, two meet the hypotheses (a ≥ 5, |S| ≥ 4):
   - 87360 = 2^6·3·5·7·13: c = 1, S = {3,5,7,13}, primes of S dividing 65: {5,13}, count 2.
   - 146361946186458562560000 = 2^18·5^4·3·7·11·13·19·37·79·109·157·313: c = 625, balance holds, S ⊆ [3,u], count 3 (13, 37, 109).
2. **Reformulated the case c = 1.** Here u = 2^a+1 is odd, and every odd prime of u must divide 2^(a+1)·∏S, so it is in S.
   So the count is exactly ω(2^a+1). H1 at c = 1 says ω(2^a+1) is bounded over all unitary perfect numbers
   2^a·(squarefree odd) with a ≥ 5 and |S| ≥ 4.
3. **Exhaustive search, c = 1, 5 ≤ a ≤ 64,** S inside [3,u] as the statement requires
   ([script](scripts/erdos1052_H1_c1_search.py), [output](scripts/erdos1052_H1_c1_search_output.txt)).
   The only solution with |S| ≥ 4 is a = 6, i.e. 87360. Method:
   - forced closure: every odd prime of L = u·∏(1+p) must join S;
   - prune when an odd prime's exponent in L exceeds 1, the power of 2 exceeds a+1, or L > R (adding primes only raises L/R);
   - otherwise branch on the least prime q of S that L is missing, over r = 2^j·q·t − 1 ≤ u (t odd).
4. **A pruning lemma** (proved on paper, not yet in Lean): if every odd prime is balanced and only a factor 2^B is short,
   no finite set T of new odd primes can close it. Σ v2(r+1) = B gives |T| ≤ B, but ∏(1+1/r) = 2^B needs (4/3)^|T| ≥ 2^B.
   My first version of the script wrongly tried only Mersenne primes in that branch; this lemma shows the branch is empty.

## Why no proof

A uniform bound on ω(2^a+1) at c = 1 looks as hard as the open finiteness question for unitary perfect numbers of
this shape. The site's own guide lists "any bound that grows with a" as a dead end. Lean could not be installed in
this cloud session (GitHub release downloads are blocked by the network proxy), so no Lean file was attempted.
